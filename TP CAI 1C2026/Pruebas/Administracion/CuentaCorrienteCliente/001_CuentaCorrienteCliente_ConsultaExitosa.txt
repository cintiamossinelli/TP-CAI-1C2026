001_CuentaCorrienteCliente_ConsultaExitosa.txt


Objetivo: Validar los escenarios en los que se concreta exitosamente la consulta de cuenta corriente del cliente.

ACLARACIÓN
Estas pruebas se diseñan desde el punto de vista del usuario. No se evalúa código interno, sino las entradas ingresadas en pantalla, las acciones realizadas y los resultados visibles esperados.

DATOS DE REFERENCIA
Clientes existentes:
- 33-63761744-9 - Adidas S.A.
- 30-64621216-9 - Nike S.A.
- 24078369 - Marcelo Gallardo

Controles principales del formulario:
- Campo CUIT / DNI / CUIL
- Botón Buscar Cliente
- Selector Fecha Desde
- Selector Fecha Hasta
- Botón Buscar
- Grilla/ListView de movimientos
- Campo Saldo
- Botón Cancelar


CASO DE PRUEBA 1

Nombre:
Consulta de Cuenta Corriente del Cliente Exitosa

Objetivo:
Verificar que el sistema permita consultar correctamente la cuenta corriente de un cliente existente con movimientos dentro del rango de fechas seleccionado.

Datos de Entrada:
- CUIT / DNI / CUIL: 33-63761744-9
- Fecha Desde: 01/01/2026
- Fecha Hasta: 10/06/2026

Precondiciones:
- El cliente Adidas S.A. existe.
- El cliente posee facturas, recibos y notas de crédito dentro del período consultado.

Pasos:
1. Ingresar 33-63761744-9 en el campo CUIT / DNI / CUIL.
2. Presionar el botón Buscar Cliente.
3. Verificar que se muestre la razón social Adidas S.A.
4. Seleccionar 01/01/2026 como Fecha Desde.
5. Seleccionar 10/06/2026 como Fecha Hasta.
6. Presionar el botón Buscar.

Resultado Esperado:
- El sistema muestra la razón social Adidas S.A.
- Se muestran los movimientos del cliente dentro del rango indicado.
- Se visualizan facturas, recibos y notas de crédito correspondientes al cliente.
- El saldo se calcula correctamente.
- No se muestran mensajes de error.
- La consulta se concreta exitosamente.

Cálculo esperado:
- Facturas: 120000 + 140000 = 260000
- Nota de crédito: -30000
- Recibo: -120000
- Saldo esperado: 110000

Resultado Obtenido: 
- El sistema muestra la razón social Adidas S.A.
- Se visualizan en el ListView las facturas, recibos y notas de crédito correspondientes al cliente.
- Se muestra el Saldo: $ 110.000,00

CASO DE PRUEBA 10

Nombre:
Consulta Exitosa y posterior cancelación

Objetivo:
Verificar que luego de una consulta exitosa el botón Cancelar limpie correctamente la pantalla.

Datos de Entrada:
- CUIT / DNI / CUIL: 24078369
- Fecha Desde: 01/01/2026
- Fecha Hasta: 10/06/2026

Precondiciones:
- El cliente Marcelo Gallardo existe.
- La consulta se ejecuta correctamente.

Pasos:
1. Ingresar 24078369 en el campo CUIT / DNI / CUIL.
2. Presionar el botón Buscar Cliente.
3. Seleccionar el rango de fechas indicado.
4. Presionar el botón Buscar.
5. Verificar que se carguen los movimientos.
6. Presionar el botón Cancelar.

Resultado Esperado:
- Primero se concreta exitosamente la consulta.
- Luego, al presionar Cancelar:
  - Se limpia el campo CUIT / DNI / CUIL.
  - Se limpia la razón social.
  - Se limpia la grilla/ListView.
  - Se reinicia o limpia el saldo.
  - Las fechas vuelven a sus valores iniciales.
- El formulario queda disponible para una nueva consulta.

Resultado Obtenido: El formulario queda disponible para una nueva consulta.

CRITERIO DE ACEPTACIÓN DE LOS CASOS EXITOSOS

Los casos exitosos se consideran aprobados si:
- El sistema identifica correctamente al cliente ingresado.
- Se muestra la razón social correspondiente.
- Se cargan únicamente los movimientos del cliente y del período seleccionado.
- Las facturas suman al saldo.
- Los recibos y notas de crédito restan al saldo.
- El saldo final coincide con el cálculo esperado.
- La consulta no duplica movimientos.
- El formulario permanece operativo luego de cada consulta.
