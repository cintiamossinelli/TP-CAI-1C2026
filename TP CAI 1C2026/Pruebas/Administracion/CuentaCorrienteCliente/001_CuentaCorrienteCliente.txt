PLAN DE PRUEBAS DE CAJA NEGRA 
Formulario: Cuenta Corriente Cliente

Caso 001 Consulta de Cuenta Corriente del Cliente Exitosa

Objetivo:
Verificar que el sistema permita consultar correctamente la cuenta corriente de un cliente existente dentro de un rango de fechas válido.

Datos de Entrada:

Cliente: 33-63761744-9
Fecha Desde: 01/01/2026
Fecha Hasta: 16/06/2026

Precondiciones:

El cliente existe en el sistema.
El cliente posee facturas, recibos y notas de crédito dentro del período consultado.

Pasos:

Ingresar el CUIT del cliente en el campo Cliente.
Presionar el botón "Buscar Cliente".
Verificar que se visualice la razón social.
Seleccionar la Fecha Desde.
Seleccionar la Fecha Hasta.
Presionar el botón "Buscar".

Resultado Esperado:

El sistema muestra la razón social del cliente.
El sistema muestra los movimientos de cuenta corriente dentro del rango seleccionado.
El sistema muestra facturas, recibos y notas de crédito correspondientes al cliente.
El saldo se calcula correctamente.
No se muestran mensajes de error.

Resultado Obtenido:

Se muestra el Saldo de la Cuenta Corriente del Cliente Buscado
