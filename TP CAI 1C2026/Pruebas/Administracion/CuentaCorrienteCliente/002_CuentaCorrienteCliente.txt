CASO DE PRUEBA 002
Formulario: Cuenta Corriente Cliente

Nombre: Consulta de Cuenta Corriente de Cliente Inexistente

Objetivo:
Verificar que el sistema informe correctamente cuando el cliente ingresado no existe.

Datos de Entrada:

Cliente: 99999999

Precondiciones:

El cliente no existe en el sistema.

Pasos:

Ingresar el identificador del cliente en el campo Cliente.
Presionar el botón "Buscar Cliente".

Resultado Esperado:

El sistema informa que no se encontró el cliente.
No se muestra razón social.
No se muestran movimientos.
No se muestra saldo.
El formulario permanece operativo.

Resultado Obtenido:
El sistema informa que no se encontró el cliente.
