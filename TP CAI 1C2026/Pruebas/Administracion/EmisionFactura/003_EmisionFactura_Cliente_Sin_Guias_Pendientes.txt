=========================================
PRUEBA DE CAJA NEGRA N° 3
CLIENTE SIN GUÍAS PENDIENTES DE FACTURACIÓN
=========================================

Objetivo:
Verificar que el sistema impida emitir una factura cuando el cliente no posee movimientos pendientes.

Precondiciones:
- El cliente existe.
- Todas sus guías ya fueron facturadas o no cumplen condiciones para facturación.

Datos de Entrada:
CUIT/DNI/CUIL: 30-64621216-9

Pasos:
1. Ingresar el CUIT/DNI/CUIL.
2. Presionar el botón "Buscar".
3. Observar la información mostrada.
4. Intentar emitir factura.

Resultado Esperado:
- Se muestra el nombre del cliente.
- La grilla aparece vacía.
- El total es $0,00.
- El sistema informa que no existen guías pendientes de facturación.
- No se genera factura.

Estado Esperado:
Rechazada.
