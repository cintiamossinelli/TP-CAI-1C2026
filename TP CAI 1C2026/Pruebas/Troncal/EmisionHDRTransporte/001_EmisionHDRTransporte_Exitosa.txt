Verificaciones:
28- El formulario queda en su estado inicial:
    - Centro de Distribución Destino sin selección
    - Empresa de Transporte sin selección
    - Fecha "11/06/2026"
    - Campo N° Guía vacío
    - Listas vacías
    - Lista de transportes y sección de guías deshabilitadas

29- Archivo HDRTransporte.json - la última entrada agregada debe ser similar a:

    {
      "NroHDR": 8,
      "IdServicio": 20,
      "FechaEmision": "<fecha actual>",
      "IdCentroDeDistribucionOrigen": 1,
      "IdCentroDeDistribucionDestino": 2,
      "Guias": [ "CD-1-820", "CD-1-824", "CD-1-816"]
    }

    IdCentroDeDistribucionOrigen debe coincidir con el CD "Rosario"
    (IdCentroDeDistribucion 1) seleccionado en el login.
    La combinación IdServicio 20 + IdCentroDeDistribucionDestino 2
    identifica la parada asignada y no debe repetirse en otra HDR.

    

30- Archivo Guias.json - la guía CD-1-816 debe aparecer con:

    {
      "NroGuia": "CD-1-816",
      "Estado": 9,
      "Historial": [
        ...entradas anteriores...,
        { "Fecha": "<fecha actual>", "Estado": 9 }
      ]
    }

31- Archivo Guias.json - la guía CD-1-820 debe aparecer con:

    {
      "NroGuia": "CD-1-820",
      "Estado": 9,
      "Historial": [
        ...entradas anteriores...,
        { "Fecha": "<fecha actual>", "Estado": 9 }
      ]
    }

32- Archivo Guias.json - la guía CD-1-824 debe aparecer con:

    {
      "NroGuia": "CD-1-824",
      "Estado": 9,
      "Historial": [
        ...entradas anteriores...,
        { "Fecha": "<fecha actual>", "Estado": 9 }
      ]
    }

33- La HDR se genera correctamente aunque las guías agregadas tengan destinos concretos diferentes.
    No se valida que todas las guías tengan el mismo destino.
34- La HDR también puede generarse con guías de distintos Centros de Distribución de origen.
    IdCentroDeDistribucionOrigen siempre toma el ID del Centro de Distribución
    seleccionado en el Login.
35- Un mismo IdServicio puede aparecer en otra HDR solamente si tiene un
    IdCentroDeDistribucionDestino diferente, es decir, otra parada.
